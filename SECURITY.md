# Security policy

## Supported version

PokeGrade is currently a local v1 prototype. Security fixes are applied to the default branch.

## Reporting a vulnerability

Do not disclose vulnerabilities, credentials, card images, or exploit details in a public issue. Report them privately through the contact method on the GitHub profile for AdenCJM.

## Handling card images

Photos uploaded for local analysis can be sensitive personal data. Do not commit user images, API keys, or environment files. Keep production deployments and third-party processing out of scope until the v2 production plan is explicitly implemented.
